BUYMAパートナー専用ツールを、Claudeなしで動かす設定手順

GitHub(ギットハブ)という無料のサービスを使って、「トレンドレーダー」と「ショップ準備ステップ」をインターネットに公開し、トレンドレーダーのデータを毎朝自動で更新します。費用はかかりません。作業時間の目安は30分です。

この手順でできるようになること
  • お客様は https://(あなたのユーザー名).github.io/(リポジトリ名)/ のようなURLで、ツールを開けます。
  • 毎朝6時40分ごろ(日本時間)に、BUYMAの人気ランキングを自動で取り込み、トレンドレーダーが更新されます。
  • Claudeにログインしていなくても、誰も操作しなくても動き続けます。

目次
1. GitHubのアカウントを作る
2. リポジトリ(ファイルの置き場所)を作る
3. ファイルをアップロードする
4. 毎朝の自動更新を設定する
5. 自動更新に書き込みの許可を出す
6. ページを公開する
7. 試しに1回更新してみる
8. お客様に渡す
9. パスワードを変えたいとき
10. うまくいかないとき

はじめに:フォルダの中身

ファイル・フォルダ中身
index.html入口のページ(2つのツールへのリンク)
trend/トレンドレーダーのページ(index.html)と、データ(data.json)
steps/ショップ準備ステップのページ
scripts/update_trend.py毎朝BUYMAのランキングを取り込むプログラム
tools/password.htmlパスワードを変えるときに使う道具
GitHub自動実行の設定/update.yml毎朝の自動更新の設定(手順4で使います)
手順書.htmlこの手順書(アップロードは不要です)

パスワードは今 buyma2026 になっています。

1. GitHubのアカウントを作る

  1. パソコンのブラウザで https://github.com/signup を開きます。
  2. メールアドレス、パスワード、ユーザー名を入れて登録します。
    ユーザー名はURLの一部になります(例:buyma-partner)。会社名やサービス名に関係する、短い英数字がおすすめです。
  3. 届いたメールの確認コードを入れて、登録を完了します。プランを聞かれたら Free(無料) を選びます。

2. リポジトリ(ファイルの置き場所)を作る

  1. GitHubの画面右上の + を押し、New repository を選びます。
  2. Repository name に名前を入れます(例:tools)。これもURLの一部になります。
  3. Public を選びます。
    無料でページを公開するには Public が必要です。ファイルの中身(ページやプログラム、BUYMAの公開ランキングのデータ)は誰でも見られる状態になります。会員限定の情報や個人情報は入れないでください。
  4. Create repository を押します。

3. ファイルをアップロードする

  1. 作ったリポジトリの画面で、uploading an existing file のリンク(または Add file → Upload files)を押します。
  2. お渡ししたフォルダを開き、次のものをまとめて画面にドラッグします。
    index.html / trend フォルダ / steps フォルダ / scripts フォルダ / tools フォルダ
  3. 画面の下の Commit changes を押します。
  4. リポジトリのトップに index.html、trend、steps、scripts、tools が並んでいればOKです。

4. 毎朝の自動更新を設定する

自動更新の設定ファイルは、パソコンでは隠しフォルダ扱いになって見えないことがあるため、GitHubの画面で直接作ります。

  1. リポジトリのトップで Add file → Create new file を押します。
  2. ファイル名の欄に、次の文字をそのまま入れます(スラッシュを入れると自動でフォルダになります)。
    .github/workflows/update.yml
  3. お渡ししたフォルダの GitHub自動実行の設定/update.yml をメモ帳(Macはテキストエディット)で開き、中身を全部コピーして、GitHubの大きな入力欄に貼り付けます。
  4. 右上の Commit changes... → もう一度 Commit changes を押します。

5. 自動更新に書き込みの許可を出す

  1. リポジトリの上のメニューから Settings を開きます。
  2. 左のメニューの Actions → General を押します。
  3. 下のほうの Workflow permissions で Read and write permissions を選び、Save を押します。

6. ページを公開する

  1. Settings の左のメニューから Pages を開きます。
  2. Build and deployment の Source を Deploy from a branch にします。
  3. Branch を main、その右を /(root) にして Save を押します。
  4. 1〜3分待って画面を再読み込みすると、上に Your site is live at … とURLが出ます。これがツールの入口のURLです。
この時点で、次のURLで開けるようになっています(ユーザー名 と リポジトリ名 はご自身のものに置き換えてください)
  • 入口:https://ユーザー名.github.io/リポジトリ名/
  • トレンドレーダー:https://ユーザー名.github.io/リポジトリ名/trend/
  • ショップ準備ステップ:https://ユーザー名.github.io/リポジトリ名/steps/

7. 試しに1回更新してみる

  1. リポジトリの上のメニューから Actions を開きます。
    「Workflows aren't being run on this repository」などと出たら、緑のボタン(I understand my workflows, go ahead and enable them)を押します。
  2. 左の一覧から BUYMAトレンド 毎朝更新 を選びます。
  3. 右の Run workflow → 緑の Run workflow を押します。
  4. 1〜2分で、一覧に 緑のチェック が付けば成功です。
  5. トレンドレーダーのページを開き、上の「○月○日の朝に更新」が今日の日付になっていれば完成です(反映まで数分かかることがあります)。

これ以降は、毎朝自動で更新されます。何もしなくて大丈夫です。

8. お客様に渡す

LINEなどで、URLとパスワードを送ります。

【パートナー様専用】BUYMAトレンドレーダーをお届けします。
BUYMAの人気ランキングをもとに、売れ筋を見やすくまとめたツールです。気になる商品にハートを付けておくと、順位の動きを追えます。
https://ユーザー名.github.io/リポジトリ名/trend/
パスワード:buyma2026

9. パスワードを変えたいとき

  1. https://ユーザー名.github.io/リポジトリ名/tools/password.html を開きます。
  2. 新しいパスワードを入れて 変換する を押すと、手順と貼り付ける文字列が出ます。その通りに、GitHubで trend/index.html と steps/index.html を書き換えます。
このパスワードは「会員限定の入口」をつくるためのかんたんな仕組みです。仕組みに詳しい人なら中身を見ることができるので、秘密の情報はツールに載せないでください。

10. うまくいかないとき

こんなとき確認すること
Actions に赤い×が付いたその行を開き、update → BUYMAのランキングを取り込む を開くとエラーの内容が出ます。
・「403」「Forbidden」:BUYMAがGitHubからのアクセスを受け付けていません。
・「アイテムが ○ 件しか取れませんでした」:BUYMAのページの作りが変わった可能性があります。
どちらの場合も、前の日のデータはそのまま残ります。エラーの文章をそのまま担当の方に共有してください。
「変更を保存する」で失敗する手順5の Read and write permissions が保存されているか確認してください。
ページが開かない(404)手順6のあと数分待ってから開き直してください。URLの ユーザー名 と リポジトリ名 が合っているかも確認してください。
更新が毎朝ではなく少し遅れるGitHubの混み具合で、数十分遅れることがあります。故障ではありません。

補足

  • BUYMAへのアクセスは1日2ページ(人気アイテムランキングと人気ブランドランキング)だけです。BUYMAの利用規約で、このような自動での読み込みが認められているかは、念のため御社でもご確認ください。
  • GitHubは、長い間何も変更がないリポジトリの自動実行を止めることがあります。このツールは毎朝データを書き込むので、通常は止まりません。もし止まった場合は、手順7と同じ画面に再開のボタンが出ます。
  • Claudeで設定していた毎朝の自動実行は、こちらに切り替えたら止めて大丈夫です。
